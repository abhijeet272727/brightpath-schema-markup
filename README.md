# BrightPath Studio — Schema Markup Practice

A small static demonstration website with JSON-LD structured data.

## What is implemented
- `Organization` schema
- `WebSite` schema
- `WebPage` schema
- Responsive HTML and CSS landing page

## Validate the schema
1. Deploy the page using GitHub Pages.
2. Open https://validator.schema.org/
3. Paste the live page URL.
4. Confirm that Organization, WebSite and WebPage are detected.
5. Capture a screenshot showing the detected items.

Google's Rich Results Test is designed for supported rich-result types. This project uses general Schema.org types, so use Schema Markup Validator as the primary validation proof.
